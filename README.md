# Highway congestion heat map: Punjab · Himachal Pradesh · Haryana

Live page: https://demoncoder-crypto.github.io/highway-heatmap/

- **Live now**: current traffic-aware travel times from the Google Routes API for 92 stretches on 8 highways, fetched in the visitor's browser and not stored.
- **Google live traffic layer**: Google's own traffic colours.
- History views (busy-hours grid, profiles, events) are SYNTHETIC test data until a licensed historical source is connected.

The Google Maps browser key in index.html must be restricted to `https://demoncoder-crypto.github.io/*` and to Maps JavaScript API + Routes API.
